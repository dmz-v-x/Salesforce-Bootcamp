## Exercise: Create a Lightning Application Named "Education"

In this exercise, we will create a Lightning Application in Salesforce and add these standard tabs:

- Home
- Accounts
- Contacts

We will do everything step by step from absolute scratch.

---

## Part 1 — Understanding What We Are Going to Build

### 1. Goal of This Exercise

We want to create a custom Lightning Application called:

Education

Inside this application, users should see:

- Home tab
- Accounts tab
- Contacts tab

This application will appear in Salesforce App Launcher.

---

### 2. What is Happening Internally

When we create a Lightning App, Salesforce creates:

- App navigation structure
- App configuration
- App settings
- Navigation tabs

We are basically creating a custom workspace for users.

---

### 3. Why We Add Tabs

Tabs help users quickly access objects and pages.

In this exercise:

#### Home Tab
Used as landing page.

#### Accounts Tab
Used to manage companies or organizations.

#### Contacts Tab
Used to manage people associated with accounts.

---

## Part 2 — Open App Manager

### 4. Login to Salesforce

Login to your Salesforce org.

You can use:
- Trailhead Playground
- Developer Org
- Sandbox

---

### 5. Open Setup

At top-right corner:

Click:
Gear Icon → Setup

This opens Salesforce Setup UI.

---

### 6. What is Setup

Setup is the administration area of Salesforce.

Here admins and developers configure:
- Apps
- Security
- Objects
- Automation
- Users

---

### 7. Find App Manager

Inside Setup:

Use Quick Find box on left side.

Search:
App Manager

Click:
App Manager

---

## Part 3 — Understanding App Manager

### 8. What is App Manager

App Manager is the place where Salesforce applications are managed.

Here you can:
- Create apps
- Edit apps
- Delete apps
- Configure navigation

---

### 9. Existing Apps

Inside App Manager you will see many existing applications like:

- Sales
- Service
- Marketing

These are standard Salesforce apps.

---

## Part 4 — Create New Lightning App

### 10. Click New Lightning App

Inside App Manager:

New Lightning App

---

### 11. What is a Wizard

A wizard is a guided step-by-step configuration process.

Salesforce uses wizards to simplify setup.

Education

## Part 7 — Navigation Style

### 20. Choose Navigation Style

Salesforce asks:

Which navigation style do you want?

Options:
- Standard Navigation
- Console Navigation

---

### 21. Choose Standard Navigation

Select:
Standard Navigation

---

### 22. Why Standard Navigation

We are creating a basic Lightning app.

Console navigation is mainly for:
- Support teams
- Service agents
- Productivity workspaces

For normal apps:
Standard Navigation is used.

---

### 23. Click Next

Proceed further.

---

## Part 8 — Add Navigation Items (Tabs)

### 24. This is the Most Important Step

Now Salesforce asks:

Which tabs should appear inside the app?

This controls app navigation.

---

### 25. Available Items Section

Left side:
Available Items

Right side:
Selected Items

---

### 26. Add Home Tab

From Available Items:
Select:
Home

Click:
Add Arrow →

Now Home appears in Selected Items.

---

### 27. What is Home Tab

Home tab acts as landing page of application.

Users usually see:
- Dashboards
- Tasks
- Reports
- Important summaries

---

### 28. Add Accounts Tab

From Available Items:
Select:
Accounts

Click:
Add Arrow →

---

### 29. What is Accounts Tab

Accounts represent:
- Companies
- Organizations
- Customers

Example:
- Infosys
- Amazon
- TCS

---

### 30. Add Contacts Tab

From Available Items:
Select:
Contacts

Click:
Add Arrow →

---

### 31. What is Contacts Tab

Contacts represent people associated with accounts.

Example:

Account:
Amazon

Contact:
John Smith

---

### 32. Arrange Tab Order

Selected Items order controls navigation order.

Arrange like this:

1. Home
2. Accounts
3. Contacts

---

### 33. Click Next

Proceed to next step.
